# Higgsfield trial art

Raw generations from the Higgsfield shot list (`Higgsfield_Trial_Shot_List.md`),
made on the free trial allowance. Numbers match the shot list.

- Clips (`.mp4`): Seedance 2.0, 4 s, 3:4, 720p, no audio, flat chroma-green
  background (#00B140). Most use the same still as start and end frame, so they
  loop back to the starting pose. Key the green, then cut frames.
- Icons (`.png`): GPT Image 2.6, 1024x1024, on chroma green.
- `MANIFEST.txt`: file name | Higgsfield generation ID | source URL.
- `NOTES.txt`: known flaws in specific clips.
