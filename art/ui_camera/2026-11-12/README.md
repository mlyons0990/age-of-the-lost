# AOTL corner-HUD artwork

Higgsfield originals, generated using the authorized free unlimited allowance. `PROVENANCE.json` records prompts, jobs, selection decisions and original hashes. No money or credits were spent.

Selected: `guardian_orb_frames_source.png`, `health_flask_source.png`, and `plaza_seam_repaired_source.png`. The other two plaza iterations are preserved for provenance but excluded from runtime. The scenery extends the original map visually; it does not create walkable districts.

Mechanical importer: `game/crownsfall_lootslice/tools/rebuild_corner_hud_art.py`. Run from a complete repository checkout with Python/Pillow. `--output /tmp/aotl-art-check` allows comparison without overwriting runtime files. See the game's `docs/REFERENCE_CAMERA_HUD_HANDOFF.md` for runtime bounds, controls and validation.
